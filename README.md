## 🚀 Getting Started

### 📦 Prerequisites

- Node.js ⚙️ (LTS recommended)
- npm / bun 🐇

### 🔧 Installation

```bash
# 1️⃣ Clone the repo
git clone https://github.com/RawatGitLab/Geoversed-Playground-AI-Solution-OPC-Private-Limited.git

# 2️⃣ Move into the project
cd Geoversed-Playground-AI-Solution-OPC-Private-Limited

# 3️⃣ Install dependencies
npm install
```

### ▶️ Run Locally

```bash
npm run dev
```

🌐 Then open **http://localhost:3000** in your browser.

### 🏗️ Build for Production

```bash
npm run build
```

### 👀 Preview Production Build

```bash
npm run preview
```
